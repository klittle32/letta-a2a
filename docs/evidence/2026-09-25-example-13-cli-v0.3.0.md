4. `task list -o json` returned both completed tasks in that context.

The target advertises no streaming, and its deterministic tasks settle too quickly for a meaningful cancellation proof.

## Agent Card incompatibility remains

The gateway-published card still uses valid strict A2A 1.0 ProtoJSON:

```json
{"securityRequirements":[{"schemes":{"a2aOAuth":{"list":["a2a.invoke"]}}}]}
```

`a2a card get` in v0.3.0 returned exit code 4 and `A2ACLI_ERR_CARD_INVALID`; its Go decoder still attempted to unmarshal the `StringList` object into a bare `[]string`. The Agent Card was not weakened or rewritten. Example 13 continues to use the CLI's supported direct-endpoint mode and records the limitation explicitly.
