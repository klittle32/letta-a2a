# Example 09 evidence — 2026-09-04

This is the concise execution record for [streaming](../../examples/09-streaming/).

## Implemented boundary

- Both Agent Cards advertise `capabilities.streaming=true`.
- The existing JavaScript and Python SDK handlers expose A2A 1.0 `SendStreamingMessage` as `text/event-stream` without a custom transport.
- The reference agent emits deterministic ordered artifact chunks with one artifact ID, correct append flags, and exactly one final chunk.
- The Letta runtime adapter projects only top-level assistant-message text into artifact chunks. Reasoning, tools, commands, subagent output, and unknown events are ignored.
- Letta runtime/provider errors collapse to a stable public failure message rather than forwarding raw internal diagnostics.
- A deterministic reference-agent SSE consumer disconnect does not cancel server-side execution; the completed task remains available through `GetTask`.

## Safety evidence

A unit test injects sentinel values into reasoning, tool-argument, and subagent assistant events. The runtime returns and publishes only the two allowed top-level assistant chunks, and the serialized public chunks contain none of the private sentinels.

Executor tests verify that successful chunks are ordered and share one artifact ID. A failure after partial generation leaves prior output non-final and publishes a failed status rather than a final artifact marker.
