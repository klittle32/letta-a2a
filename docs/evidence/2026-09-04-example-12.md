## Live Hermes and ADK proof

The official Hermes image was launched against OpenAI `gpt-5-mini`; the ADK service used its live LiteLLM-backed `openai/gpt-4.1-nano` model. `gpt-4.1-nano` was not retained as the Hermes default because the pinned Hermes OpenAI Responses path sends `reasoning.effort`, which that model rejected. `gpt-5-mini` completed the same tool path.

Two unattended Hermes one-shot turns used the stock `a2a_call` tool and one A2A context:

```text
STORED
ctx-9764f65860764cff

You asked me to remember the codeword LANTERN. Context ID: ctx-9764f65860764cff
```

Hermes's own plugin audit independently recorded both outbound tool calls:

```json
{"direction":"outbound","peer":"google-adk","task_id":"task-cacb4d09470042b2","summary":"Remember the codeword LANTERN and reply STORED."}
{"direction":"outbound","peer":"google-adk","task_id":"task-23972a302d1e44c3","summary":"What codeword did I ask you to remember?"}
```

The interactive `hermes --tui` path was then launched through a real pseudoterminal. `/tools` exposed `a2a_call`, and a paced operator prompt produced a visible `A2a Call` event followed by the response that the ADK agent had stored `COMPASS`. Agentgateway recorded the completed task under context `ctx-9ff373b037cd4baf`; the ADK observation recorded request `task-c555861c00f94c8b`, message `746a4a41a9bd4b50be2ba6225f7d7e41`, the same context, and `authorizationPresent:false`.

After moving both model-provider credentials behind temporary read-only secret-file mounts, the final `bun run test:example-12:live` check passed with context `ctx-3f11a303b8b64cab`. It derives continuation from Hermes's one authoritative `a2a_conversations/ctx-*.jsonl` filename rather than model-authored terminal prose. The script deleted its unique containers, networks, state volume, and temporary key file.

No client secret or access token appeared in the inspected auth-server, agentgateway, or ADK logs. Raw terminal capture was not committed because it contains ANSI redraw noise and user/model text; only the reviewed correlation summary is retained here.

## Proven limits

- Live wording varied; only tool provenance, identity, route, context continuity, and semantic recall were asserted.
- The pre-existing full live matrix hit one transient push callback/readback mismatch on its first final run; an immediate isolated rerun passed all protocol, push, streaming, delegation, and cancellation checks. No Example 12 path participated in the failed assertion.
- The TUI uses a real attached terminal. The unattended live check uses Hermes one-shot mode because ordinary CI stdin is not a TTY.
- Hermes named-peer configuration and Docker network separation fix the demonstrated path. Gateway authorization remains role/scope based rather than subject-to-route based.
- Access tokens are short-lived process environment values, not production-grade hardware-backed secrets.
- ADK persistence remains process-local and was not tested across recreation.
